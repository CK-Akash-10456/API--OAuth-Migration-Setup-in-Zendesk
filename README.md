# Zendesk OAuth Setup

## Files

| File | Purpose |
|------|---------|
| `OAuth_Generate.py` | OAuth auth module — auto-refreshes tokens, pass as `auth=` to requests |
| `first_run.py` | Interactive OAuth setup wizard (run once) |
| `credentials.json` | Saved tokens (auto-generated by first_run.py) |

## 1. Run Setup (once)

```bash
pip install requests
python first_run.py
```

This walks you through the OAuth flow and saves tokens to `credentials.json`.

To change scopes (default: read-only), edit `SCOPE` in `first_run.py:44`.

## 2. Use in Code

```python
from OAuth_Generate import ZendeskOAuth

auth = ZendeskOAuth()
requests.get("https://sub.zendesk.com/api/v2/users/me.json", auth=auth)
```

That's it. Tokens auto-refresh before expiry and persist back to `credentials.json`.

## Manual Construction

```python
auth = ZendeskOAuth(
    subdomain="mycompany",
    oauth_token="abc...",
    oauth_refresh_token="def...",
    oauth_client_id="my-client",
    oauth_client_secret="secret",
)
```
